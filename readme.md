# 🛒 AI E-Commerce – MERN Stack

## 📌 Project Overview

AI E-Commerce is a full-stack e-commerce web application built using the MERN Stack.

The application allows users to browse products, search for products, view product details, manage their shopping cart, securely authenticate, and place orders.

The project also includes AI functionality to provide a smarter and more user-friendly shopping experience.

---

## 🚀 Features

### 👤 User Features

- User Registration and Login
- JWT-based Authentication
- Secure Password Hashing
- Browse Products
- Product Search
- Product Details
- Add to Cart
- Update Cart Items
- Remove Cart Items
- Place Orders
- View Order Details
- Responsive User Interface

### 🤖 AI Features

- AI-powered user assistance
- Natural-language interaction
- AI-generated responses
- Smart shopping assistance

### 🛠️ Admin Features

- Admin Authentication
- Add Products
- Update Products
- Delete Products
- Manage Products
- Manage Orders
